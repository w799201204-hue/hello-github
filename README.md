## 怎么运行

先确认电脑上装好了 Python，然后在当前目录执行：

```
python hello.py
```

预期输出：

```
Hello, GitHub!

```

## 常用 Git 命令

```
git status             查看当前有哪些改动
git add .              把改动放进暂存区
git commit -m "说明"    提交一次记录
git push               推送到 GitHub
```
